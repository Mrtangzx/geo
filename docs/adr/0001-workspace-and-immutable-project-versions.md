# ADR-0001：从首阶段保留工作区归属和不可变资料版本

状态：采纳。日期：2026-10-31。关联任务：GitHub #1。

## 背景

R2 要求回答分析、基线、发布核验和复查报告均能还原当时依据。首阶段先运行本地单用户版本，随后才引入邀请登录；延后工作区归属或覆盖历史资料都会破坏后续证据与授权边界。

## 决策

- 使用 PostgreSQL 与 Drizzle 保存品牌项目及不可变版本，不采用浏览器存储、内存或文件作为生产持久化替代。
- 服务端确定工作区与操作者，仓储操作显式接受工作区归属；本地预览使用固定工作区，后续身份认证在相同边界注入上下文。
- 品牌资料和企业事实变更在事务中生成新快照；事实保留稳定标识、确认状态、确认者与确认时间。
- 编辑请求携带预期版本，版本冲突返回明确错误，不能覆盖其他编辑或改写旧版本。
- 缺少数据库配置或连接失败显示待配置与具体错误，不回退成看似已保存的内存或文件模式。
- 合成标识随项目保存，默认不加载合成企业或假回答。

## 结果

本地预览也能验证真实数据库持久化、历史与并发编辑；后续邀请登录无需重建资料归属。此决策不代表已完成跨账号隔离、真实采样或效果验收。
