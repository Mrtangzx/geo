# ADR-0002：先用合成材料推进工程验证

状态：采纳。日期：2026-10-31。

## 用户决定

用户引用“准备平台测试资料与模拟流程”聊天，并明确回复“先用合成材料”。当前阶段使用现有 R2 合成包跑通完整工程流程，不执行真实付费调用。

## 决策与执行

- 保留 R2 的完整业务目标和 23 张任务票，不将工程演练等同于真实消费端、真实企业或真实效果验收。
- 合成企业、回答、页面、标注、费用和观察日期保留来源与合成标记；原始数据和标准答案分别保存，标准答案不作为真实模型输入。
- 演练必须由用户明确选择，不因凭证缺失静默回退为假回答；真实通道仍显示待配置或待验证，真实额度默认零。
- 后续工程实现可以在前置接口与数据契约已经完成的基础上使用隔离的合成回放继续推进。仅因真实账号、真实日期或真实客户不足而未关闭的前置票，不阻止该工程演练；正式验收仍遵守原阻塞关系。
- 每张票分别记录工程验证范围和剩余真实验收。真实通道、首家真实企业案例及三至五家真实试点没有对应证据时保持未完成，不关闭其验收票。
- 页面合成快照使用专门的回放适配，不放开生产抓取器的本机、内网或文件访问限制。
- 历史日期只能作为明确的演练时钟；真实调度与采集时间不被回写。模拟金额与真实账单分开，不据此发起付费调用。

## 影响

可以在没有付费凭证的情况下完成可操作的资料、采样、分析、修改、核验和报告工程验证；商业数据质量、模型效果及真实试点仍需另外取得证据。
