# 操作界面调整验收

日期：2026-11-02。依据用户指定的 `stitch-design-taste` 技能，设计基准保存为根目录 `DESIGN.md`。本轮修改操作界面，没有把平台剩余任务重新定义为已完成。

## 实现

- 主导航明确四步：品牌资料、检查结果、修改任务、复查报告；项目、资料版本和合成标识在各页可见。
- 品牌页分为“品牌与企业事实”和“买家问题与版本”，提供继续检查的入口。
- 检查页分为回答与指标、采集资料、页面诊断、额度账本和监测计划。采集先选人工来源或合成回放，故障演练与账本不再挤在结果页。
- 回答按时期筛选，支持搜索和状态过滤；列表与原文/引用/人工复核详情并排。切换分区不卸载采集草稿，加载时显示未知占位。
- 任务按状态筛选，队列与详情并排；详情按真实阶段显示下一步，依据和历史逐步展开。发布时间按北京时间输入，再转换UTC。
- 报告自动打开最新版本，历史侧栏独立保留；按复查时期和问题组查看，保留分子分母、限制、窗口及下载入口。
- 统一无衬线字体、中性背景与绿色操作强调色；增大正文、表单和44px操作目标，移动端改为单列。
